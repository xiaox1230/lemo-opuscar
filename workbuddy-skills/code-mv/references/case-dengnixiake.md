完整的 31 镜见工程的 `storyboard.md`。**结构上的可复用点**：

1. **首尾闭合**：01 和 31 是同一棵树、同一盏灯，只有光线和季节变了。这是最便宜、最有效的"结束感"。
2. **每镜留一个物理钩子**：蒸汽、伞面、柱子、发梢、纸角、衣角。相邻镜靠这个钩子连，不靠叙事连。
3. **副歌必给脸**：第 10 镜（星空）之后紧接第 11–12 镜的近景，副歌的情绪落点是人脸。
4. **间奏用空镜**：18 镜一个镜头里放三个空镜（上摇），撑住 23 秒的间奏，成本几乎为零。
5. **人群对比**：16 镜里主角是唯一有颜色的人。孤独不用演，对比就出来了。

## 三、时长是怎么定的

```
镜长 = 下一句歌词的起点 − 0.18（留白）− 本句起点
夹在 [1.7s, 6.8s] 之间
```

- 1.7s 是"中文读得完"的下限，6.8s 是"观众不会以为字幕卡住"的上限。
- 例外：第一镜 15.3 秒（前奏空镜），第 18 镜 23 秒（间奏），第 31 镜 23.6 秒（尾声）。
  这三镜**没有歌词**，所以不受上面的夹取约束——但它们必须有画面内运动，否则会判定为幻灯片。
- 相机速度反算：`|Δx| / 镜长`。全部镜头的速度要么是 0，要么 ≥ 12px/s。中间地带一律砍掉。

## 五、复现这套片子要跑的命令

```sh
LIB=$(sh scripts/find-lib.sh | sed -n 's/^LIB=//p')

# 0) 量歌
"$LEMO_PY" scripts/analyze_song.py song.mp3

# 1) 歌词
"$LEMO_PY" scripts/make_lyrics.py lyrics.lrc --dur 270 --outdir films/my-song

# 2) 分镜表（手写 storyboard.md，再机械转成 shots.json）
#    31 行，每行 n/t0/t1；建议用 5 行 Python 从 lyrics.json 生成，别手抄

# 3) 渲画面
node $LIB/core/render/video.mjs films/my-song --fps 24 --workers 6 --out films/my-song/out/video.mp4

# 4) 混流
ffmpeg -y -v error -i films/my-song/song.mp3 -t 270 -ar 48000 -ac 2 -c:a pcm_s16le films/my-song/out/mix.wav
sh $LIB/core/render/mux.sh films/my-song/out/video.mp4 films/my-song/out/mix.wav films/my-song/out/film.mp4 24 0

# 5) 自检
"$LEMO_PY" scripts/selfcheck.py films/my-song/out/film.mp4 \
  --shots films/my-song/shots.json --lyrics films/my-song/lyrics.json \
  --native 320x180 --end-card 258
```

## 六、如果重做一次，会改什么

- **05 镜的 5px/s 慢移**应该直接去掉。它是全片唯一一个"卡着动"的地方，`selfcheck` 会以 0.17s 的等间隔跳变把它标出来。
- **纸艺 / 蜡笔样片的 `Math.random()`** 在样片阶段没暴露（只出了单帧），但做成全片会在分段接缝处突变。这一点已经写进两个画风的模板。
- **拆信镜（17）的信纸**应该在 6 秒内抽完，不要留"停住"的空档。现在它是匀速抽出的，观感正确；但这也是唯一一个"动作比歌词慢"的镜头。
