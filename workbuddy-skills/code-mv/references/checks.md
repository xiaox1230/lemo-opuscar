# 自检：五类翻车点怎么量、量到什么算合格、不合格怎么改

工具：`scripts/selfcheck.py`（从成片 mp4 反测，不看源码）

```sh
LIB=$(sh scripts/find-lib.sh | sed -n 's/^LIB=//p')
"$LEMO_PY" scripts/selfcheck.py out/film.mp4 \
  --shots film/shots.json --lyrics film/lyrics.json \
  --native 320x180 --end-card 258
```

`--native` 用**逻辑分辨率**：像素风传 `320x180`，2D 直绘传 `480x270`。
不是越大越好——分析分辨率超过逻辑分辨率，等于在数放大后的重复像素，会把"没动"算成"动了"。

---

## 1) 像幻灯片

**指标**：每镜"每秒变化像素占比"的中位数 + 最长"完全静止"秒数。

| 数值 | 含义 |
|---|---|
| 中位数 < 0.02% | 这一镜基本是静态图，观众会走神 |
| 最长静止 > 1.2s | 明显"卡住"（片尾署名卡除外，用 `--end-card` 排除） |
| 中位数 2–7% | 健康 |
| 中位数 > 15% | 每帧都在整屏重绘，通常是闪烁，不是运动 |

**不合格时按顺序改**：

1. **先加"画面内运动"**，不要先加运镜：蒸汽、落叶、笔尖、秒针、人潮、车轮、光斑挪动、尘埃。
   一个 0.3% 的常量运动就能救活一整镜，而且不会引入抖动。
2. 还是不够，再动相机。但位移/时长必须 ≥ 12px/s（320×180 下的经验值），否则会变成"卡顿"。
3. 实在没有可动的东西，就**换镜**——静止的大全镜最多留 8 秒。

> 反例：把一镜的相机从 0 慢慢移到 -20px（5 秒），得到的是 4px/s——比不动还难看，因为它在"卡着动"。

## 2) 运镜晃 / 硬跳

**指标**：孤立跳变——某帧的差值远大于前后两帧（`> max(1.0, 4×邻居)` 且 `> 3%`）。

注意：这是**镜内**检测。镜头切点本来就该是硬的，脚本会自动把 `shots.json` 里 `t0/t1 ±0.25s` 的命中排除掉。

判硬跳用的是另一套阈值（`--pop-diff`，默认 40，即单像素变化 > 40 级才算）：
1px 位移会让整屏纹理"变一点"，面积很大但每像素只变十几级；真正的硬跳是少数像素变几十级。
用面积判会把所有平移都报成跳变。

**不合格时**：

| 现象 | 真正的原因 | 改法 |
|---|---|---|
| 每隔 0.2–0.5s 跳一次，等间隔 | 循环粒子相位 `1→0` 硬接 | 让粒子在画面外重置，或用 `(ph + 1) % 1` 的连续写法 |
| 等间隔、幅度很大 | 慢速平移每 N 帧挪 1px | 提速到 ≥12px/s 或改成静止 |
| 只在某一帧 | 灯亮/闪白直接切整屏颜色 | `fb.dissolveDark(1-ramp)` 有序溶解，配合 2 帧抖动 |
| 在镜头边界附近但不在边界上 | 上一镜的最后一帧和下一镜的第一帧构图差太远 | 加"前景物扫过"（树叶/衣角/柱子）做遮挡转场 |

## 3) 表现力不够

**指标**：长句（≥10 汉字，多半是副歌）落在哪个镜头、那一镜有没有人物 + 动作。

规则（不是美学，是可执行的检查）：

- 副歌（`analyze_song.py` 里 `kind: loud` 的段）里，**至少 2/3 的镜头要有人的脸**（近景或中近景）。
- 每个副歌段至少有一次**景别跳变**（大全 → 近景，或反过来）。
- 连续 3 个镜头不能都是同一景别。
- 全片至少有一次"不拍人"的空镜，放在间奏。

**不合格时**：把副歌前那句改成无声的空镜（蓄势），副歌第一句直接给近景。观众的感受是"终于看到了"。

## 4) 道具不对

**指标**：`--props` 传一张 `{"信":[80.9,87.3],"伞":[100.1,106.9]}` 的时间轴，和分镜表对照。

道具的三条硬规则：

1. **首次出现必须在歌词提到它之前 1–2 秒**（先看见，后听见——反过来就像"解说"）。
2. 出现过的道具必须有归属：谁拿的、放在哪。凭空出现在画面中央的道具会让观众分神。
3. 结局要回收一次（信被拆、伞被收、气球飞走）。不回收的道具是废笔。

## 5) 歌词没演出来

**指标**：每句歌词 → 对应镜头 → 那一镜有没有对应动作/事件。脚本会列出全部映射，并报出"没有镜头覆盖"的歌词。

**不合格时的三种情况**：

| 症状 | 改法 |
|---|---|
| 一句歌词跨了两个镜头 | 调整 `SHOTS` 的 `t0/t1` 对齐歌词，或把两句合成一镜 |
| 镜头里的动作和歌词无关 | 换动作（`act`）或换 plate；宁可换成"手/脚/背影"的特写，也不要"人在念歌词" |
| 长句只停留 1.7s | 字幕读不完。合并到下一句（`make_lyrics.py --merge`），或把镜长拉到 ≥ 字的个数 / 4.2 秒 |

字数与时长的换算：中文舒适阅读约 **4.2 字/秒**。一句 12 字需要 ≥ 2.9 秒。
`make_lyrics.py` 会在超过 7 字/秒时打警告。

## 补充：混流阶段的两个隐性问题

这两项 `selfcheck.py` 不查，但一定要看一眼：

```sh
ffmpeg -i out/film.mp4 -af ebur128 -f null - 2>&1 | tail -8
ffprobe -v error -show_entries stream=codec_name,width,height,r_frame_rate,duration -of default=nw=1 out/film.mp4
```

| 项 | 合格值 | 不合格的症状 |
|---|---|---|
| 响度 | −14 ± 1 LUFS，TP ≤ −1.2 dBFS | 上传后被平台二次压缩，忽大忽小 |
| 帧率 / 时长 | 24/1，与 `DUR` 一致（如 270.000） | 音画不同步，越到后面越明显 |
| 分辨率 | 1920×1080，yuv420p | 某些播放器黑屏（`yuv444` 不兼容） |

`mux.sh` 里已经做了两遍 `loudnorm`，正常不用手调。如果改过 `song.mp3` 的增益，重跑一次 `mux.sh` 即可，不必重渲画面。
