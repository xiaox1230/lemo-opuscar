# 蜡笔手绘绘本（Canvas 2D 直绘，1920×1080）

适合：童年、愿望、日记体、有点傻气的真诚。它的记忆点不是"精细"，是**线在动**。

## 一、一个函数撑起整个画风

```js
crayon(pts, col, { wobble, hatch, grainAmt, seed, stroke })
```

五步，顺序不能换：

1. **手抖轮廓** —— 顶点按 `wobble` 位移，用 `quadraticCurveTo` 连（不用 `lineTo`，直线会显得是尺子画的）
2. **块面填色** —— `globalAlpha = .93`，留一点纸的呼吸
3. **斜向笔触** —— 同一支蜡笔来回涂，`rgba(0,0,0,.55)` 每 9px 一道，留缝；再叠一道白色每 13px
4. **纸纹镂空** —— `destination-out` + 颗粒遮罩：**蜡只挂在纸的凸起上**，这一步是"像蜡笔"的关键
5. **重描轮廓** —— 深色线，`lineWidth 6`，不闭合，两头故意出线

第 4 步的遮罩是一张 256×256 的黑白噪点图，`fillStyle = createPattern(grain, 'repeat')`，
按 `seed` 偏移 —— 同一个 `crayon()` 因为偏移不同，颗粒位置不同，画面就不会"复印感"。

## 二、沸腾线（boiling line）

```js
const fr = Math.floor(t * 12);      // 12fps
const S = 1 + fr * .0137;           // 每帧换一个种子
crayon(pts, col, { seed: S + 7 });
```

- 12fps 是手绘动画的经典帧率。低于 10 会跳，高于 15 就"太滑"，不像手画的。
- 种子的间隔要**足够小**（0.0137）：轮廓只抖 1–2px，才像同一只手在重描，而不是每帧换一个人画。
- 只有线条和颗粒随 `fr` 变，**几何位置不能变**。位置一变就是"画面在抖"。

## 三、纸与罩染

```js
// 纸：暖白 + 9 万颗纸点 + 400 根纤维
// 罩染：一道玫瑰色水彩，multiply 混合，globalAlpha .55
```

罩染是"统一色调"的工具：不管各个色块选了什么颜色，最后都被一层玫瑰色拉进同一个色温。
**只用一道。** 两道就脏，三道就糊。

## 四、比例

蜡笔绘本用 **2.5 头身**（`hr = h * .19`），比纸艺更圆。特征：

- 点状眼（`arc(r=4)`），不用眼白
- 腮红是两块半透明圆，几乎每个表情都画——这是"可爱"的最大来源
- 嘴用 `arc` 的上半/下半弧区分笑/哭，不要画牙齿

## 五、这套画风的坑

| 症状 | 原因 | 修法 |
|---|---|---|
| 每帧纸纹不一样（接缝处最明显） | 纹理/颗粒/水痕用了 `Math.random()` | 全部换 `rnd(i)`；这是本画风最容易犯的错 |
| 像"填色本"而不是蜡笔 | 少了第 4 步纸纹镂空 | `destination-out` + `grain`，`grainAmt .3–.46` |
| 线条像矢量图 | `lineTo` 直连 + 没有 wobble | 用 `quadraticCurveTo`，`wobble 2.2` |
| 画面在抖（晕） | 几何位置也用了 `S` 当种子 | 位置用固定常量，只有 `wobble`/`grain` 随 `S` 变 |
| 颜色脏 | 罩染叠了多层 | 只留一道 `multiply` |
| 头发盖住脸 | 画头 → 画头发 → 忘了把脸补回来 | 必须最后再画一次脸的椭圆（`hr*.74`） |

## 六、性能

`crayon()` 每次都新建一个离屏 canvas、clip、打图案、再 drawImage。单帧 40–80 个色块时，
1080p 下一帧 40–70ms，比纸艺略快（蜡笔的块面更少）。

全曲的实用做法：

- 12fps 步进意味着 24fps 的相邻两帧**有一半是完全相同的**。渲染器不会帮你省，但你可以：
  ```js
  window.render = t => {
    const fr = Math.floor(t * 12);
    if (fr === lastFr && cache) { ctx.drawImage(cache, 0, 0); return texts; }
    ...
  };
  ```
  注意 `cache` 是跨帧状态，只能当**纯缓存**用（丢了也只是重画一次），不能参与画面计算，否则违反纯函数。
- 或直接把成片渲成 12fps，再用 `ffmpeg -vf fps=24` 补：观感完全一致，渲染时间减半。
